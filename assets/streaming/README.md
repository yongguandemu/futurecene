## 直播姬搭建步骤

### 1. 添加背景
添加「图片」素材 → 选择你的背景图（1920×1080，自备），铺满全屏，置于最底层。

### 2. 添加 Live2D 形象（小恶魔）
直播姬本身不能直接导入 .model3 模型，用 **VTube Studio** 桥接：

1. 下载 VTube Studio（Steam 免费版即可，允许商业直播）：https://store.steampowered.com/app/1325860/VTube_Studio/
2. 把模型文件夹 `d:\future scene\LumiProject\assets\live2d\小恶魔` 整个拖进 VTube Studio 窗口完成导入
3. VTube Studio 中打开「虚拟摄像头」（Settings → Virtual Camera → 开启），开摄像头后模型会通过虚拟摄像头输出
4. 直播姬添加「摄像头」源 → 选择 VTube Studio 虚拟摄像头
5. 摄像头源缩放至左侧大屏区（约 784×958，x=96 y=56），裁剪背景只留角色

### 3. 按坐标添加素材
直播姬「图片」素材逐一添加，位置对齐上表坐标。素材均为透明 PNG，直接叠加不会遮挡背景。

### 4. 添加文字（文本素材）
- 顶部信息条内：主播名（如「小恶魔 Lilith」）、今日话题，白色/薰衣草紫 `#C9A7FF`，微软雅黑粗体
- 底部栏：歌单提示、状态（如「正在播放：xxx」）
- 弹幕面板：直播姬自带「弹幕互动」功能可叠加，或用文本源演示弹幕

### 5. 弹幕区
两种方式任选：
- 直播姬自带弹幕面板/弹幕互动功能（自动获取真实弹幕）
- 或把 `panel_danmu.png` 作为背景框，上面叠文本源模拟弹幕

## 想换配色？

所有素材均由脚本生成（`make_streaming_assets.py` 在本地缓存），修改脚本顶部配色常量后重新运行即可整套换色，无需手动改图。需要换色时告诉我目标色板即可。
