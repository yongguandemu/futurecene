# 控制界面与智能助手合并实施计划（路线 A · 去重合并）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `/dashboard/`（控制界面）与 `/assistant/`（智能助手）合并为单页面单入口，实现一个页面、一个 store、一条 WS 连接；`/assistant/` 重定向到 `/dashboard/#assistant`。

**Architecture:** dashboard 保留现有 store/state_sync 作为唯一状态源；assistant 的 chat/schedule/config 视图 HTML+CSS+JS 迁入 dashboard；master/overview/state 合并为"系统总览"，orchestrators/modules 合并为"调度官管理"；assistant 独有 JS 全部改用 dashboard 的 store，删除 assistant 自己的 store 实例。

**Tech Stack:** 原生 HTML/CSS/JS（无构建），Flask 路由。

**Spec:** `docs/superpowers/specs/2026-08-14-ui-merge-design.md`
