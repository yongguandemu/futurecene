# Future Scene · 功能升级路线图（未迁移功能储备清单）

> 本文档整理自旧系统（LumiProject）《旧项目资产与功能清单》中标记"否/可选"未迁移的功能，
> 以及 2026-08-15 迁移审计确认的缺失项，作为**未来升级空间**的索引。
> 更新日期：2026-08-15

---

## 0. 如何使用本文档

- **缺失待补（§1）**：审计确认"应该迁移但没迁"的项，建议近期优先补齐。
- **升级储备（§2-§9）**：旧系统标"否"未迁移的功能，按领域归类。每一项都标注旧实现、
  价值与建议触发时机——**什么时候业务/场景到了，就回来取用**。
- **已被替代（§10）**：旧系统标"否"但新系统已用等价实现覆盖的功能，避免重复投入。
- **无需迁移（§11）**：工程工具类，新系统已有更优方案。

## 1. 缺失待补（审计确认）

| 功能 | 旧实现 | 状态 | 优先级 | 说明 |
|------|--------|------|--------|------|
| 日程/排期调度 | `core/schedule_engine.py` + `core/schedule_service.py` | **缺失** | P0 | 旧系统"日程驱动功能开关""排期引用场景自动激活"；新系统无任何日程模块。PPT 中"排期管理"依赖此项才真实 |
| LLM 工具调用 | `core/tool_registry.py` + `core/skill_bus.py` + `core/director.py` | **缺失** | P1 | 旧系统 LLM 可调工具（点歌/画图等）；新系统意图路由为纯规则，LLM 无工具能力 |
| lumi 停用角色清理 | `config/profiles/lumi/` | **遗留缺陷** | P0 | 目录已标"已停用"，但 `all_roles()` 仍枚举，多角色协作会误注册；应排除或删除 |

## 12. 升级优先级总览

| 优先级 | 范围 | 建议 |
|--------|------|------|
| P0 | 日程调度、lumi 清理 | 近期补迁（PPT 功能真实性依赖日程） |
| P1 | LLM 工具调用 | 中期，能力差异明显 |
| P2 | 表现增强类、轻量工具类 | 表现力/性能专项时 |
| P3 | LLM 运营内容类、数据画像类 | 积累真实直播数据后 |
| P4 | 可观测/自愈运维类 | 上云多实例后 |
| P5 | 交互扩展类、平台边缘类 | 产品形态扩展时（桌宠/C 端/MCP 生态） |
