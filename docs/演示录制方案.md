# Future Scene · 演示视频录制方案（2026-08-16）

> 目标：为息壤杯商业计划书配套的 3-5 分钟演示视频。
> 系统已实测联通：14 调度官、世界书 472 条、全页面可访问（见下）。

## 0. 录制规格

| 项 | 值 |
|---|---|
| 时长 | 3-5 分钟 |
| 分辨率 | 1920×1080（16:9），30fps |
| 声音 | 麦克风口播讲解（不入 TTS 声，避免串音） |
| 工具 | OBS Studio（推荐）或 Win+G 录屏 |

## 1. 录制前准备（10 分钟）

```bash
# 1. 确认 .env 有真实 Key（OPENAI / ZHIPU / DASHSCOPE 必填）
# 2. 启动服务（跑通一轮再录）
python run.py --no-browser
# 3. 自测：浏览器打开 http://127.0.0.1:5000/dashboard/ 确认页面与数据正常
# 4. 自测链路（另开终端，发一条弹幕看日志）
python scripts/demo_danmaku.py "主播今天讲什么故事呀？"
# 5. 检查网络稳定（LLM/TTS 走云 API，断网即卡）
```

## 2. 分镜脚本（6 段，建议一次录完或分段录）

| # | 段落 | 画面 | 时长 | 口播要点 |
|---|---|---|---|---|
| 1 | 开场 | 总控制台 `/dashboard/`，从左到右扫过 | 20s | 一人成军的 AI 虚拟主播系统；看直播也能管直播 |
| 2 | 世界书 | `/worldbook/`：472 条设定，5 大分类；展示自动进化条目（重要观众/常驻观众） | 30s | 人格一致性怎么保证——世界书 + 弹幕/礼物自动进化 |
| 3 | Live2D 角色 | `/live2d/`：Yuki 模型加载、表情动作 | 20s | 软件渲染无显卡也能跑；角色会表演 |
| 4 | 弹幕互动（核心） | 终端跑 `demo_danmaku.py` 发 2-3 条弹幕，同屏展示字幕叠加 `/subtitle/` | 60s | 全链路：弹幕→安全→记忆→LLM→字幕→TTS→口型；记得住观众 |
| 5 | 智能助手管理直播（独一份亮点） | 总控制台/命令入口：切角色、点歌、查状态 | 30s | AI 不只当主播，还当直播管理员——切角色、点歌、备播一句话搞定 |
| 6 | 排期 + 成本 | 总控制台排期管理 + 口播成本页 | 20s | cron 排期到点自动开播；月成本约 ¥93，约 1 元/小时 |
| 7 | 结尾 | 回到封面/感谢页 | 10s | 息壤育智 · 一人成军 |

**重点**：第 4、5 段是区别于同类产品的核心（自主直播链路 + 智能助手管理），多给镜头。

## 3. OBS 录制设置建议

- 采集：显示器采集（1080p）
- 若做直播演示画面：把 `http://127.0.0.1:5000/live2d/` 和 `/subtitle/` 作为浏览器源叠进画面（本方案录屏可不用）
- 音频：桌面音频关（避免 TTS 声），麦克风开
- 输出：mp4，质量高，30fps

## 4. 风险与兜底

| 风险 | 应对 |
|---|---|
| LLM/TTS API 断连 | 提前跑通一轮；断连时切静态页面讲解，口头说明"实时链路已演示" |
| demo_danmaku 加载旧模型 | 脚本加载"小恶魔"模型；如需 Yuki 可改 `scripts/demo_danmaku.py` 第 41 行 `model_name` 或直接口播带过 |
| 录制中断 | 分段录（每段一个文件），最后拼接，避免重录整场 |
| 口播卡壳 | 每段录前先念一遍口播要点（上表"口播要点"列） |

## 5. 录完自检清单

- [ ] 第 5 段智能助手命令执行成功
- [ ] 口播声音清晰、无 TTS 串音
- [ ] 时长 3-5 分钟，1080p
